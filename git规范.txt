# ① 先拉取远程最新（好习惯，避免冲突）
git pull

# ② 新建/修改文件：写你的 事件循环.md

# ③ 看看改了什么（最常用）
git status

# ④ 加入暂存区（. 表示所有改动）
git add .

# ⑤ 提交并存档（说明写清楚！）
git commit -m "新增：事件循环博客"

# ⑥ 推到远程
git push



⚠️ 五个注意点
注意
说明
先 pull 再 push
如果你在别的电脑上改过，先 pull 把远程的拉下来，避免冲突
commit 说明要写清楚
写 "新增：事件循环博客"，别写 "update"——面试官会翻你的提交历史
千万别用 git push -f
强制推送会真的覆盖远程历史，新手最容易闯祸，看到 -f就躲开
git add . vs git add 文件名
. 提交全部改动；只想提交某一个文件就写文件名
push 又报 443
网络问题（你上次遇到过的），换网络/重试即可，你的 commit 是安全的


git log                      # 看历史，找到想回去的版本号
git checkout -- 文件名        # 单个文件恢复到最后一次提交的版本
git reset --hard 版本号       # 整个仓库回到某个版本（危险，会丢未提交改动）
